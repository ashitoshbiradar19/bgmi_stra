1. WEB WORKER OFFLOADING FOR WATER-LOCK PIXEL SAMPLING (src/workers/waterWorker.js)
================================================================================
• Dedicated Web Worker (`src/workers/waterWorker.js`):
  - Moved heavy pixel-sampling loops off the main UI thread into a Dedicated Web Worker.
  - Implemented asynchronous message passing (`postMessage`) for water surface ratio calculations under Stage 4+ circles.
  - Prevents UI frame drops and guarantees smooth 60+ FPS interaction during fast circle dragging on mobile/tablet devices.
• Quantized Position Cache & Fallback Engine (`src/lib/water.js`):
  - Added spatial key quantization (`Math.round(x/10)`) to cache sampling results during drag operations.
  - Provides instant response without redundant pixel lookups.

================================================================================
3. DEMAND-DRIVEN CANVAS RENDERING & MEMORY LEAK PREVENTION (src/components/MapCanvas.jsx)
================================================================================
• Demand-Driven Render Scheduler (`requestRender`):
  - Replaced the continuous 60 FPS animation loop with an event-driven render trigger (`requestRender`).
  - Redraws occur strictly when viewport, map state, annotations, tools, or pointer interactions change (0% CPU draw overhead when idle).
• Direct DOM Coordinate Readout:
  - Cursor grid coordinates update directly via `coordRef.current.textContent` on pointer move.
  - Bypasses React `useState` re-renders on mousemove/touchmove, eliminating 120Hz React component re-rendering overhead.
• Resource & Thread Cleanup:
  - Complete unmount cleanup for Web Workers, animation frame requests, resize observers, and DOM event listeners to prevent memory leaks during multi-hour tournament analysis sessions.
